01

@container

Les styles réagissent à la taille du conteneur, pas seulement à la fenêtre du navigateur. Cela permet de créer des composants adaptatifs plus robustes.

.card {
  container-type: inline-size;
}

@container (min-width: 22rem) {
  .card { background: #22c55e; }
}

02

:has()

Le sélecteur :has() permet de cibler un parent selon ce qu’il contient. C’est pratique pour styliser des cartes ou des formulaires selon leur contenu.

.card:has(input:checked) {
  border-color: #38bdf8;
  box-shadow: 0 0 0 3px rgba(56,189,248,.2);
}

text-wrap: balance

Cette propriété améliore la ligne de titre en répartissant mieux les mots. Le résultat est plus lisible sans modifier le contenu HTML.

h2 {
  max-width: 18ch;
  text-wrap: balance;
}

05

@property

@property permet de déclarer un type de variable personnalisé. Cela rend les animations et les valeurs CSS plus sûres et plus prédictibles.

@property --progress {
  syntax: "<number>";
  inherits: false;
  initial-value: 0;
}

.bar { width: calc(var(--progress) * 1%); }

06

@layer

Les layers permettent de contrôler la priorité des feuilles de style. C’est utile pour organiser une architecture CSS propre et éviter les conflits.

@layer theme {
  .button { background: #f97316; }
}

@layer base {
  .button { background: #d1d5db; }
}

Le layer theme a plus de priorité que le layer base.

07

light-dark()

La fonction light-dark() choisit automatiquement une couleur selon le thème du système. C’est très pratique pour les interfaces qui doivent s’adapter au mode clair / sombre.

.card {
  color: light-dark(#111827, #f3f4f6);
  background: light-dark(#fff, #111827);
}

08

clamp()

Clamp() permet de limiter une valeur entre un minimum et un maximum avec un comportement fluide. C’est très utile pour les tailles responsive.

.title {
  font-size: clamp(1.2rem, 2vw, 2.5rem);
  width: clamp(15rem, 50vw, 40rem);
}

Le scrolling peut s’arrêter sur des points précis. C’est particulièrement pratique pour les carrousels ou les pages sectionnées.

.gallery {
  display: grid;
  grid-auto-flow: column;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
}

aspect-ratio

La propriété aspect-ratio permet de donner une proportion fixe à un bloc sans calcul manuel. Le layout reste cohérent sur tous les écrans.

.media {
  aspect-ratio: 16 / 9;
  width: min(100%, 24rem);
}
